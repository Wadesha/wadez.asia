# 开发历史记录

本目录保存 wadez.asia 项目开发过程中所有生成的页面、组件和关键内容快照。

## 目录结构

```
docs/history/
├── README.md                    # 本文件
└── 2026-07-22/                  # 按日期归档
    ├── session-summary.md       # 会话摘要（需求 + 决策 + 操作）
    └── components-snapshot.md   # 当日生成的组件清单和关键代码
```

## 归档规则

1. 每次开发会话结束后，在对应日期目录下创建记录
2. `session-summary.md` 记录：需求讨论、技术决策、操作步骤、遇到的问题
3. `components-snapshot.md` 记录：当日新增/修改的文件清单和核心逻辑说明
4. 重大版本变更时，可额外保存完整页面快照

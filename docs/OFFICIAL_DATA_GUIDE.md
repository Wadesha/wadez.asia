## 🏛️ 数据源详情

### 1. 北京市公共数据开放平台

**数据量**: **76,283条记录**(完整覆盖所有线路)

**数据字段**:
- 线路名称
- 方向(上行/下行)
- 站点序号
- 站点名称

**开放条件**: **无条件开放**

**获取步骤**:

#### Step 1: 注册账号
```
访问: https://data.beijing.gov.cn
点击右上角"注册" → 填写信息 → 登录
```

#### Step 2: 获取唯一标识码
```
登录后 → 用户中心 → 唯一标识码
```

#### Step 3: 配置环境变量
在项目根目录的 `.env.local` 文件中添加:
```bash
BEIJING_DATA_KEY=你的唯一标识码
```

#### Step 4: 执行脚本获取数据
```bash
npx tsx scripts/fetch-official-data.ts
```

**预计耗时**: 30分钟(不含注册时间)
